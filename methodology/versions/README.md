# Версии методологии

Каждая версия — принятый срез методологии на определённый момент времени. 
Версии иммутабельны: принятая версия не изменяется, новая версия создаётся 
отдельно.

## Список версий

| Версия | Статус | Дата | Описание |
|--------|--------|------|----------|
| [v0.1.0](./v0_1_0/) | Историческая | 2026-07-06 | Первая структура системы мета-информации над проектом |
| ... | ... | ... | ... |

## Как выбирать версию

- **Для изучения:** начните с самой ранней, чтобы увидеть эволюцию мысли
- **Для применения:** используйте последнюю принятую версию
- **Для понимания и углубления:** читайте [заметки автора](../notes/) 

## Статусы версий

- **Историческая** — ранняя формулировка, не для применения, из черновиков
- **Принятая** — стабильная версия для использования
- **Устаревшая** — заменена более новой принятой версией
