# Принципы работы, выполняемые в данной архитектуре

1. **Append-only для логов и задач** - исторические записи не редактируются,
   только дополняются новыми файлами.
2. **Грануляция по смыслам** - каждая сущность отвечает за одну конкретную
   область (стандарты, логи, инструменты, задачи).
3. **Атомарность по действиям** - каждое действие логируется и по возможности
   отделяется от другого действия, чтобы за один атом git изменений не было
   много разных изменений в проектах.
4. **Стандартизация через жизненный цикл** - стандарты проходят путь от
   эксперимента (`buffered/`) до официальных (`main/`).
5. **Автоматический контроль через daemons** - фоновые процессы предотвращают
   ошибки и поддерживают актуальность.
6. **Декларативность через шаблоны** - LLM заполняет шаблоны, а не генерирует
   свободный текст.
7. **Человек в контуре для критических решений** - breaking changes в
   стандартах, повышение версий, архитектурные выборы - только после валидации
   человеком.
8. **Человек в контуре для контроля** - система делает паузы в ожидании
   одобрения поведения человеком, чтобы тот мог корректировать вектор
   генерации, отлавливать нововведения и артефакты прошлых этапов генерации.
