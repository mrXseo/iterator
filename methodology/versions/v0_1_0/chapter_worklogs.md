# Worklogs

Прозрачность работы связки нейросети&человек и заметки над проектом.

`worklogs` - это папка с логами, которые генерируются по ходу работы с
проектом. Сюда не входят рабочие артефакты, вроде прямой аналитики, это слой
записей действий и смыслов в хронологическом порядке, чтобы можно было
отследить какие информационные сущности порождают другие информационные
сущности, какие действия к чему приводят и к чему привязаны, и с какой точки
можно отменить при случае изменения.

В папке `worklogs` будут папки:

> `logs_genval.{somethink}` - утилита, генератор-валидатор шаблонов для логов,
> чтобы они были унифицированны и полны. Использует из папки `patterns/`
> утилиты/декларативы/конфигурации чтобы проверять и создавать логи.

> `patterns_reg.md` - таблица названий паттернов (видов) логов, описаний для
> них, в каких случаях они порождаются.

> `patterns/` - хранилище паттернов в виде утилит/декларатив/конфигураций для
> генерации и валидации логов.

> `{PATTERN_NAME}/` - хранилище файлов логов конкретного шаблона.

Каждый лог, который будет порождаться, обязан иметь вид и путь:

```
~root/"worklogs"/"{PATTERN_NAME}"/"{TIMESTAMP like DD.MM.YYYY HH:MM} {PATTERN_NAME}.{somethink}"
```
