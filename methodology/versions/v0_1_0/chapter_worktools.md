# WorkTools

Утилиты для автоматизации совершения работы.

Инструменты по автоматизации процессов, вроде создания директорий с анализом
покрытия тестами, и проверкой заполнения данной директории данными.
Находятся данные утилиты в `work_tools/` и структура данной папки следующая:

> `tools.md` - таблица по запуску инструментов. В таблице будет ссылка на
> инструмент как на файл для запуска, а рядом в колонке соседней указаны
> инструкции как запускать для желаемого результата, и рядом ссылка на
> документацию по утилите, даже если это небольшой файл `help.md`.

> `{TOOL_NAME}/` - папки с используемыми инструментами.

> `{TOOL_NAME}/help.md` - файл, который должен прилагаться даже к
> однофайловой утилите на python, если нет другой документации по запуску. На
> данную документацию по запуску должна быть ссылка в `tools.md`
