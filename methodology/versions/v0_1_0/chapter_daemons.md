# Daemons

Фоновые валидаторы.

Фоновые утилиты, нужные для того, чтобы проверять ограничения проекта и
работы, не позволяя исполнителям ошибаться или забывать о выходе из окна
контролируемой разработки.

Примеры Daemons:

> Безопасность удаленного git репозитория - следит за использованием git
> инструментов и не позволяет пользоваться инструментами взаимодействия с
> удаленной веткой git без явного подтверждения через password.

> Валидация логирования работы - периодически сканирует `worklogs` применяя к
> файлам логов их валидаторы, проверяя в автономном режиме корректность записей
> в логах, чтобы не нарушалась корректность отчетности и просмотра. Так же может
> делать суммы байтов для логов с достаточно большим сроком существования, чтобы не было
> подмены файлов.

> Проверка атомарности коммитов - проверяет периодически количество файлов, в
> которых были совершены изменения в соответствии с git. Если файлов измененных
> много, то daemon напоминает о том, что может начать нарушаться атомарность
> правок в git, что скажется на точности отката при повреждениях и неполадках.

> Регистрация инструментов - проверяет `work_tools/` на наличие
> незарегистрированных инструментов, уведомляет о необходимости добавить
> инструмент в `tools.md`.

> Актуальность стандартов - проверяет файлы на соответствие актуальным версиям
> стандартов из `workflow_docs/`. Уведомляет и предлагает создать задачи в
> `worklogs/` для устаревших файлов через `troubles` или что-то такое.

Под контролем разработки в общем виде подразумевается возможность как можно
более точного прослеживания, отката и предсказуемого внесения изменений в
проект.

Располагаться фоновые утилиты все будут в `daemons/` и подразумевают запуск
при запуске работы в IDE.
