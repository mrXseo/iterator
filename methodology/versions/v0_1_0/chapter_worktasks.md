# WorkTasks

К каким целям должны прийти при разработке.

В папке `work_tasks` должны располагаться документы на поставление целей и
задач для разработки, даже если это плохо сформулированное ТЗ. Как и в
`worklogs`, здесь нельзя редактировать файлы, а вместо этого создается файл с
правками на целевой файл или копия целевого файла, в который будет вноситься
правка.
