# Введение

Данный документ определяет сущности и структуры сущностей, которые нужны для
отслеживания разработки проекта или множества проектов, не перегружая
LLM/человека контекстом по проекту/множеству проектов, и позволяет больше
гранулировать работу по смыслам, выполняя конкретные задачи по конкретным
стандартам или целям.
