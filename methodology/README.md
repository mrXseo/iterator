# Методология Iterator

## Как читать?

Методология развита через последовательность версий. Каждая версия — 
самостоятельная книга с введением, главами и рекомендуемым порядком чтения.

Подробнее [здесь](./versions/README.md).

## Какой публичный формат?

Все версии в репозитории являются публичными, но для презентаций существует набор материалов [здесь](./portal/).
